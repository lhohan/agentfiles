name: interrogate-plan
description: Inspect the codebase first, then interview the user relentlessly about every aspect of the plan until reaching shared understanding. Use when a plan needs analysis or when assumptions remain unresolved after inspection.
---

Before asking clarifying questions, first inspect the codebase using available read-only tools to find relevant answers. Discuss relevant findings with the user if the codebase contains useful information related to the question and topic.

Interview the user relentlessly about every aspect of this plan until reaching shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommended answer.

Ask the questions one at a time.

Once all choices are resolved, stop asking confirmatory questions. Do not re-confirm decisions the user has already accepted.
