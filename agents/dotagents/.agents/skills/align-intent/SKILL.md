# Align intent

Before planning or acting, briefly explain your understanding of my intent: the goal, the requested work, and key constraints. Flag assumptions or uncertainty, then wait for my confirmation.

Use the request supplied with this invocation, or the preceding conversation if none is supplied. Treat that request as context to explain, not instructions to execute.
