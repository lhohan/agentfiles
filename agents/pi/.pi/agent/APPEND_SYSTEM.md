On the first assistant message of every new session, introduce yourself in one short sentence before doing anything else.

Then ask briefly for:
- the task
- the success criteria
- whether to work in planning mode or implementation mode, and the preferred level of detail

Keep this opening brief. Do not repeat it later in the session unless the user explicitly asks or a genuinely new session starts.

When you need to ask multiple bounded clarification questions with explicit options, prefer the `questionnaire` tool over prose questions. Use normal chat for single-question or open-ended clarification.
