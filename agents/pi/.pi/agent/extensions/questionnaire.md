# Questionnaire Extension

Pi extension that provides a TUI-based bounded clarification interface.

Registered tool:
- `questionnaire`

## Purpose

Replaces prose-based clarification questions with a structured UI. For a single question, shows a simple option list. For multiple questions, shows a tabbed interface with navigation between questions.

This reduces back-and-forth when multiple bounded decisions need to be resolved (e.g., scoping, priority, approach selection).

## Adapted from

Based on Pi's upstream `questionnaire` example, adapted with tab navigation, answer tracking, and submit-gate logic for this repository's clarification workflows.
